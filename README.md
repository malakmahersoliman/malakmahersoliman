## 🌌 A Little About Me

I love figuring out **how things work behind the scenes** — and turning that curiosity into software people can actually use.

- 💻 **My direction:** software engineering, especially **backend development** and building real systems.
- 🏦 **My favorite space:** **banking & fintech** — payments, wallets, digital experiences, and the logic behind them.
- 🌱 **Currently learning by building:** **Java, Spring Boot, PostgreSQL, REST APIs**, and backend fundamentals.
- 🧩 **Also built with:** **C#/.NET, Angular, Kotlin**, and Python. Mobile development is where my journey began.
- ✨ **My approach:** understand the *why*, then build the *how*.
